### INAC Sistemas Ltda
**Desenvolvedor Full Stack**  
`Outubro de 2025 - Atual`

Atuo no desenvolvimento de aplicações web e sistemas digitais com foco em
arquitetura escalável, automação de processos e integração de APIs.

**Principais entregas**

- Reestruturação do principal sistema da empresa com `Next.js`, modernizando
  uma plataforma crítica de gestão de eventos.
- Construção de uma interface unificada para controle de acesso,
  credenciamento, emissão de credenciais e disparo de comunicações.
- Integração com leitores faciais, catracas, e fluxos operacionais ligados a
  eventos presenciais.
- Desenvolvimento e manutenção de APIs e integrações com serviços externos,
  incluindo a `API da Meta (WhatsApp)`.
- Criação de uma API intermediária para orquestração de integrações e controle
  de envios em larga escala.
- Desenvolvimento de um SaaS de análise de sites com IA para geração de
  insights automatizados de SEO e performance.

### Supermercado Castanha
**Auxiliar de TI**  
`Setembro de 2024 - Março de 2025`

retrabalho e aumentando a eficiência operacional.
